# Category 9 — Gesällprov

The mandatory capstone is an independently designed application combining techniques from earlier assignments. It must be strong in both form and function and must not merely repeat an earlier exercise.

| ID | Official Swedish title | Type |
|---|---|---|
| 9 | Gesällprov | Mandatory |

The final submission includes source code and `beskrivning.pdf`, covering the title, summary, development process, construction, and demonstrated functionality. Create the capstone directory from [`docs/assignment-template.md`](../../docs/assignment-template.md) when planning begins.
